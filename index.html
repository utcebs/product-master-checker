Existing attribute types

Master Attribute Types.xlsx (loaded automatically)
Export from D365 → Data management → entity Product attribute value types (the sheet it writes is Product_attribute_value_types)
Lets the check say which attribute types already exist and which conflict with them. Re-export it whenever attribute types are added in D365 — a stale list will call real attributes new.

Attribute groups

Attribute Group Master.xlsx (loaded automatically)
Export from D365 → Data management → entity Product attribute group attribute assignments (the sheet it writes is Product_attribute_group_attrib)
Which attribute types are already linked to which attribute group. An attribute type existing is not the same as it being linked to the group that needs it, and this is what tells the two apart.
